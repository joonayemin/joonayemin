# web1

## 대리점-본사 메신저 데모

이 프로젝트는 **브라우저에서 바로 확인할 수 있는 실시간 메신저 데모**입니다.

---

## 0. 정말 완전 초보용 요약 (딱 4단계)

1. **Node.js 설치**
2. **프로젝트 폴더 열기**
3. 터미널에서 `npm install` 실행
4. 터미널에서 `npm start` 실행 후 브라우저에서 `http://localhost:4173/messenger.html` 접속

---

## 1. 먼저 준비할 것

### 1-1) Node.js 설치
- https://nodejs.org 접속
- **LTS 버전** 다운로드/설치
- 설치 중 옵션은 기본값 그대로 진행해도 됩니다.

### 1-2) 설치 확인
터미널(또는 명령 프롬프트)에서 아래 2개를 입력:

```bash
node -v
npm -v
```

- 버전 번호가 나오면 정상입니다. (예: `v20.x.x`, `10.x.x`)

---

## 2. 프로젝트 폴더 열기

프로젝트 폴더가 `joonayemin`이라면, 터미널에서 해당 폴더로 이동하세요.

예시:

```bash
cd /workspace/joonayemin
```

> 본인 PC에서는 경로가 다를 수 있습니다. (예: `C:\Users\내이름\Downloads\joonayemin`)

---

## 3. 실행 방법 (처음 1회 + 매번 실행)

### 3-1) 처음 1회만: 라이브러리 설치

```bash
npm install
```

- 인터넷이 되는 환경에서 실행해야 합니다.
- 이 단계는 처음 한 번만 하면 됩니다.

### 3-2) 데모 서버 실행

```bash
npm start
```

정상 실행되면 서버가 켜지고, 터미널은 실행 상태로 유지됩니다.

---

## 4. 브라우저에서 접속

- 메인 페이지: http://localhost:4173
- 메신저 페이지: http://localhost:4173/messenger.html

> **중요:** 서버를 실행한 같은 PC에서 접속해야 합니다.

---

## 5. 실시간 데모 확인하는 방법 (추천)

실시간 동작 확인을 위해 아래처럼 해보세요.

1. 브라우저 탭을 2개 엽니다. (또는 크롬 + 엣지)
2. 두 탭 모두 `http://localhost:4173/messenger.html` 접속
3. 탭 A에서 메시지 전송
4. 탭 B에서 실시간으로 반영되는지 확인

이렇게 하면 “실시간 메신저”처럼 동작하는 걸 바로 볼 수 있습니다.

---

## 6. 서버 종료 방법

서버를 켠 터미널 창에서:

- **Windows/Linux/Mac 공통:** `Ctrl + C`

## 7. 초보자 문제 해결 (에러별)

### 문제 A) `npm` 또는 `node` 명령을 못 찾는다고 나옴
- 원인: Node.js 미설치 또는 설치 후 터미널 재시작 안 함
- 해결:
  1. Node.js LTS 재설치
  2. 터미널 완전히 종료 후 다시 열기
  3. `node -v`, `npm -v` 재확인

### 문제 B) `npm install`에서 권한/403/네트워크 에러
- 원인: 회사/기관 네트워크 정책, 프록시, 방화벽
- 해결:
  1. 개인 인터넷(핫스팟)에서 재시도
  2. 사내망이라면 네트워크 관리자에게 npm registry(`registry.npmjs.org`) 접근 요청

### 문제 C) 브라우저에서 페이지가 안 열림
- 확인 체크리스트:
  1. 터미널에서 `npm start`가 켜져 있는지
  2. 주소 오타 없는지 (`http://localhost:4173/messenger.html`)
  3. 포트 충돌 시 터미널 오류 메시지 확인 후 기존 프로세스 종료
